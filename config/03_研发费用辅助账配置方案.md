# 03 研发费用辅助账配置方案（高企认定 + 加计扣除）

> 适用对象：数据库核心产品开发 + 数字化/安全/AI 实施项目类公司
> 核心目标：建立**可被税务和专家评审认可**的研发费用辅助账

---

## 一、为什么这块最要命

### 1.1 政策硬要求

| 事项 | 要求 |
|---|---|
| **高新技术企业认定** | 明确要求建立**研发费用辅助账** |
| **研发费用加计扣除** | 需按项目设置辅助账，凭证齐全 |
| **汇算清缴** | 需完成"辅助账汇总数 = 财务报表 = 所得税申报表"三方数据校验 |

### 1.2 三条铁律（违反直接被否）

| # | 铁律 | 说明 |
|---|---|---|
| 1 | **按月登记、按月核对** | 切忌年底集中补账，**时间倒填会被直接质疑** |
| 2 | **研发费用与生产经营费用严格隔离** | 人为调剂、虚增研发费用是**严重涉税违规** |
| 3 | ⭐ **分摊必须有真实使用记录支撑** | 见第五节，这是评审最常挑的地方 |

---

## 二、8 类研发费用的定义

| # | 费用类别 | 典型内容 |
|---|---|---|
| 1 | **人员人工费用** | 研发人员工资薪金、五险一金、外聘研发人员劳务费 |
| 2 | **直接投入费用** | 材料、燃料动力、模具、样品样机、检验费、仪器设备租赁费 |
| 3 | **折旧费用** | 用于研发的仪器、设备折旧 |
| 4 | **无形资产摊销** | 软件、专利权、非专利技术摊销 |
| 5 | **设计费用** | 新产品设计费、新工艺规程制定费 |
| 6 | **装备调试费用与试验费用** | 工装准备、临床试验、勘探开发技术现场试验 |
| 7 | **委托外部研发费用** | 委托境内外机构或个人研发 |
| 8 | **其他费用** | 差旅、会议、知识产权申请费、外聘专家咨询费 等 |

---

## 三、⚠️ 两个口径差异（最容易算错的地方）

| 项目 | **加计扣除口径** | **高企认定口径** |
|---|---|---|
| **其他费用上限** | ≤ 可加计扣除总额的 **10%** | ≤ 研发总费用的 **20%** |
| **委托研发** | 按实际发生额的 **80%** 计入 | 按实际发生额计入（境内）/ 80%（境外） |
| 人员人工 | 直接从事研发的人员 | 累计实际工作 183 天以上 |

> ⚠️ **同一套数据，两套限额。** 报表里应当**分两列显示**（加计扣除口径 / 高企口径），避免在评审或税务核查时被挑错。

## 四、ERPNext 数据模型设计

### 4.1 第一步：新增会计维度（Accounting Dimension）

**路径**：`Accounting → Accounting Dimensions → New`

| 维度名 | 用途 | 是否必填 |
|---|---|---|
| **研发项目**（R&D Project） | ⭐ 把费用归到具体研发项目 | 建议必填 |
| **项目**（Project） | ERPNext 原生，用于交付类项目 | — |
| **业务线**（Business Line） | 产品 / 数字化 / 安全 / AI | 建议必填 |
| **部门**（Cost Center） | ERPNext 原生 | — |

> 💡 ERPNext 的会计维度就是中国财务说的**辅助核算**。理念是"**科目保持简洁，分析交给维度**"——同一笔"管理费用-差旅费"不用拆科目，只要打上 研发项目 + 部门 + 业务线 三个标签。
>
> ⚠️ **建议维度总数不超过 5 个**。维度越多，录单越麻烦，工程师填工时的意愿越低——而这会直接毁掉整个辅助账的质量。

### 4.2 第二步：建"研发项目"主数据

**新建自定义 DocType：`研发项目`**

| 字段 | 类型 | 说明 |
|---|---|---|
| 项目编号 | Data | 如 RD-2026-001 |
| 项目名称 | Data | |
| 立项日期 | Date | |
| 计划完成日期 | Date | |
| 项目负责人 | Link → Employee | |
| 研发类型 | Select | 自主 / 委托 / 合作 |
| 项目状态 | Select | 立项 / 进行中 / 已完成 / 已终止 |
| 预算金额 | Currency | |
| 是否资本化 | Check | 影响资本化/费用化 |
| 成员名单 | Table | 参与人员及投入比例 |

### 4.3 第三步：建立费用归集链路

所有研发相关支出，**在录入时就要打上"研发项目"标签**：

| 费用类型 | 录入入口 | 必填维度 |
|---|---|---|
| 人员人工 | **工时单（Timesheet）** + 薪资分配 | 研发项目 |
| 直接投入 | 采购发票（Purchase Invoice） | 研发项目 |
| 折旧 | 资产折旧凭证（Asset Depreciation） | 研发项目 |
| 无形资产摊销 | 摊销凭证（Journal Entry） | 研发项目 |
| 委托外部研发 | 采购发票（服务类） | 研发项目 |
| 其他费用 | 费用报销（Expense Claim） | 研发项目 |

> ⭐ **这条链路的成败 90% 取决于工时**。建议用硬约束把填工时绑进日常流程（如"不填工时不能提交报销"），详见第八节。

### 4.4 第四步：研发支出科目结构

```
5301 研发支出（分组）
  ├─ 530101 费用化支出（末级）    → 期末结转至 6604 研发费用
  └─ 530102 资本化支出（末级）    → 结转为无形资产/开发支出
```

- **费用化**：不符合资本化条件的，计入当期损益
- **资本化**：符合条件的（技术可行性确立、有意图完成、能带来经济利益等），计入无形资产

## 五、⚠️ 分摊规则：评审最常挑的地方

### 5.1 反面案例（真实评审）

> **浙江某新材料公司**，2024 年将一间**共用实验室**的折旧费和水电费共 60 万元，在 A、B、C 三个研发项目上**平均分摊**，每项 20 万元。
>
> 专家评审追问：三个项目分别在不同时期使用该实验室——**A 项目只运行了 3 个月就终止，C 项目用了整整 12 个月且设备满负荷运转。凭什么 A 和 C 分摊一样多？**
>
> 评审组最终按**实际使用时长**重新计算分摊比例，发现 A 项目只能分摊约 **5 万元**，之前多计的 **15 万元被从研发费用中剔除**。虽然该公司最终因其他条件尚可通过、经补充说明后涉险过关，但被要求**专项答辩**，给评审组留下"财务管理不严谨"的印象，整体评分大受影响。

### 5.2 三条分摊原则

| # | 原则 |
|---|---|
| 1 | ❌ **不能"搞平均"** |
| 2 | ⭐ **必须基于真实的使用记录**（设备运行日志、实验记录、项目进展报告、考勤工时） |
| 3 | ⭐ **同一分摊方法要保持一贯性**（不能今年按人员比例、明年按工时） |

### 5.3 常用分摊依据

| 共用资源 | 推荐分摊依据 |
|---|---|
| 共用人员 | **工时记录**（按项目实际投入工时占比） |
| 共用设备 | **设备运行日志**（按实际台时） |
| 共用场地 | **使用面积 × 使用时长** |
| 共用软件/平台 | 按**账号活跃度或使用时长** |
| 公共水电 | 按**设备功率 × 运行时长** |

> 🔑 **要有原始记录可查**。ERPNext 里的工时单（Timesheet）就是最天然的原始记录 —— 这也是为什么工时质量决定一切。

## 七、软件即征即退（顺带说明，同属你这类公司必做）

**政策依据**：财税〔2011〕100 号

| 项目 | 规则 |
|---|---|
| 适用 | 增值税一般纳税人销售**自行开发生产**的软件产品 |
| 机制 | 按 13% 征收后，对**实际税负超过 3% 的部分即征即退** |
| 前提 | 需**软件产品登记**（软著 + 检测报告） |

**应退税额计算公式**：
```
应退税额 = 软件产品销项税额 − 软件产品销售额 × 3% − 无法划分的进项税额中应由软件产品分摊的部分
```

**ERPNext 落地**：自定义报表，筛选软件产品类销售发票的销项税与对应进项税，按公式计算。

## 八、工时质量：整个方案的成败关键

**说句不客气的**：ERPNext 的工时模块很好用，但**这个项目成败 90% 取决于"工程师愿不愿意每天认真填工时"**。

| 症状 | 后果 |
|---|---|
| 周五下午补填一周工时 | 工时分布失真 → 项目成本失真 → **加计扣除基数失真** |
| 研发与项目工时混填 | 加计扣除基数和项目成本**双错** |
| 管理层不查工时 | 系统沦为摆设 |

### 四个解法

| # | 做法 |
|---|---|
| 1 | **工时前置** —— 把"填工时"绑进日常流程（如不填工时不能提交报销/不能合并代码） |
| 2 | **颗粒度控制** —— 挂到"项目 + 任务"即可，不要细到分钟（工程师会抗拒） |
| 3 | **月度复核** —— 项目经理每月签认本项目工时，**签认后锁定** |
| 4 | **挂钩考核** —— 项目毛利进项目经理考核 |

## 十、一句话提醒

> **研发费用辅助账的核心不是"报表怎么画"，而是"数据从哪来"。**
>
> 只要**凭证在录入时就打对了"研发项目"标签**，辅助账就是自动生成的副产品；如果凭证是月底手工编的，**时间倒填 + 分摊无依据**，评审一定挑出来。
>
> **先解决工时质量，再谈报表。**
